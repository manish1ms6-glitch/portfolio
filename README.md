# ManishDevOps Portfolio

Static portfolio website for `manishdevops.in`.

## Files
- `index.html` - main website
- `styles.css` - styling and responsive layout
- `script.js` - mobile navigation and footer year

## Before publishing
Update these placeholders in `index.html`:
- GitHub URL
- Email address
- Resume link

## Deployment
This is a static website. It can be deployed to GitHub Pages, Azure Static Web Apps, AWS S3 + CloudFront, Netlify, Vercel, or another static hosting service.

For `manishdevops.in`, point the domain DNS records to whichever hosting provider you choose and enable HTTPS.
